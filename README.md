## 📌 About This Repository

This repository is a centralized collection of my **Full Stack Development practical experiments**.

The objective is to understand and implement important concepts involved in modern web application development, including:

- RESTful APIs
- Spring Boot
- Java Backend Development
- Database Integration
- Authentication & Authorization
- JWT Security
- Role-Based Access Control
- Redux State Management
- React-based Applications
- API Integration
- CRUD Operations
- Performance Optimization
- Calendar & Scheduling Systems
- Backend–Frontend Communication

The experiments are organized in a single repository for easier management, learning, testing, and reference.
